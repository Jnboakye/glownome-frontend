# Google Sign-In Setup Guide

## What Was Fixed

**Problem**: Tapping "Continue with Google" did nothing in Expo Go because:
1. `supabase.auth.signInWithOAuth()` in React Native only returns `data.url` - it doesn't open a browser
2. The code ignored `data.url` and did nothing
3. The hardcoded redirect `glownome://auth/callback` doesn't work in Expo Go (needs `exp://`)

**Solution**: Implemented proper OAuth flow using `expo-auth-session` and `expo-web-browser`:
- Uses `makeRedirectUri()` to generate correct URIs (exp:// in Expo Go, glownome:// in builds)
- Opens OAuth URL with `WebBrowser.openAuthSessionAsync()`
- Handles the callback with PKCE code exchange
- Properly handles cancellation and errors

## Required Supabase Configuration

### Step 1: Add Redirect URLs in Supabase Dashboard

Go to **Supabase Dashboard → Authentication → URL Configuration → Redirect URLs**

**Add these redirect URLs**:

#### For Expo Go Development:
```
exp://**
```
This wildcard allows all exp:// URLs (Expo Go uses dynamic URLs based on your project/device).

**Specific examples** (logged in console when you run the app):
- `exp://192.168.1.42:8081` (your LAN IP)
- `exp://127.0.0.1:8081` (localhost)
- `exp://<your-project-id>.exp.direct:80/--/auth/callback` (Expo Go production)

#### For Production Builds:
```
glownome://auth/callback
```

#### Recommended: Add Both Wildcards
For maximum flexibility during development:
- `exp://**` (Expo Go)
- `glownome://**` (dev/production builds)

**Screenshot Location**:
Supabase Dashboard → Your Project → Authentication → URL Configuration → Redirect URLs

---

### Step 2: Configure Google OAuth Provider in Supabase

Go to **Supabase Dashboard → Authentication → Providers → Google**

1. **Enable** the Google provider
2. Enter your **Google Client ID** (from Google Cloud Console)
3. Enter your **Google Client Secret** (from Google Cloud Console)
4. **Save**

---

### Step 3: Configure Google Cloud Console

Your **Supabase OAuth callback URL** must be added to Google Cloud:

1. Go to **Google Cloud Console → APIs & Services → Credentials**
2. Select your **OAuth 2.0 Client ID** (web application)
3. Under **Authorized redirect URIs**, add:
   ```
   https://<your-project-ref>.supabase.co/auth/v1/callback
   ```
   
   **Example**:
   ```
   https://hatsybfzmtfkqaxqnkfq.supabase.co/auth/v1/callback
   ```

4. **Save**

**How to find your Supabase URL**:
- Supabase Dashboard → Settings → API → Project URL
- It's the same as `EXPO_PUBLIC_SUPABASE_URL` in your `.env`

## How It Works

### The OAuth Flow

```
1. User taps "Continue with Google"
   ↓
2. App calls supabase.auth.signInWithOAuth({
     provider: 'google',
     options: {
       redirectTo: makeRedirectUri({ path: 'auth/callback' }),
       skipBrowserRedirect: true
     }
   })
   ↓
3. Supabase returns data.url (Google OAuth consent page)
   ↓
4. App opens data.url in WebBrowser.openAuthSessionAsync()
   ↓
5. User signs in with Google
   ↓
6. Google redirects to Supabase callback:
   https://YOUR-PROJECT.supabase.co/auth/v1/callback
   ↓
7. Supabase processes OAuth and redirects to your app:
   exp://YOUR-IP:PORT/--/auth/callback?code=PKCE_CODE
   (or glownome://auth/callback?code=PKCE_CODE in builds)
   ↓
8. WebBrowser returns result to app
   ↓
9. App calls supabase.auth.exchangeCodeForSession(code)
   ↓
10. Session is established, user is signed in!
```

### Redirect URI Behavior

| Environment | Redirect URI | Format |
|-------------|--------------|--------|
| **Expo Go** | Generated by makeRedirectUri() | `exp://192.168.1.42:8081/--/auth/callback` |
| **Dev Build** | Custom scheme from app.json | `glownome://auth/callback` |
| **Production Build** | Custom scheme from app.json | `glownome://auth/callback` |

The app **logs the redirect URI** to the console on mount, so you can see exactly what to add to Supabase.

## Troubleshooting

### "Invalid redirect URI" error

**Cause**: The redirect URI used by the app is not in Supabase's allowed list

**Solution**:
1. Check the console log: `[SignInScreen] OAuth Redirect URI: ...`
2. Copy that **exact** URI
3. Add it to Supabase Dashboard → Authentication → Redirect URLs
4. Or use wildcards: `exp://**` and `glownome://**`

### "Browser result: cancel"

**Not an error** - user cancelled sign-in. The app handles this gracefully (no alert shown).

### "No authentication code or tokens found"

**Cause**: Supabase didn't redirect properly, or the redirect URI is wrong

**Solution**:
1. Verify Google OAuth is enabled in Supabase
2. Verify Google Client ID/Secret are correct
3. Verify Supabase callback URL is in Google Cloud Console
4. Check redirect URI is in Supabase allowed list

### Browser doesn't open

**Cause**: `expo-web-browser` not installed or configured

**Solution**:
```bash
npx expo install expo-web-browser
npx expo start -c
```

### "Error: Could not open browser"

**Cause**: Expo Go might need permissions or is restricted

**Solution**:
- Try on a different device/simulator
- Make sure Expo Go has permission to open URLs
- Check if device has a default browser set

### Session not persisting after sign-in

**Cause**: SecureStore or session handling issue

**Solution**:
1. Check console for `[useAuthSession] Auth state changed: SIGNED_IN`
2. Verify `expo-secure-store` is installed: `npm list expo-secure-store`
3. Clear app data and try again

## Google Cloud Console Setup (Full Guide)

If you haven't set up Google OAuth yet:

### 1. Create a Google Cloud Project

1. Go to https://console.cloud.google.com
2. Create a new project (or select existing)
3. Enable **Google+ API** (if not enabled)

### 2. Create OAuth 2.0 Credentials

1. Go to **APIs & Services → Credentials**
2. Click **+ CREATE CREDENTIALS → OAuth client ID**
3. Choose **Web application**
4. Name it (e.g., "Glownome Supabase Auth")
5. Under **Authorized redirect URIs**, add:
   ```
   https://YOUR-PROJECT.supabase.co/auth/v1/callback
   ```
6. Click **Create**
7. Copy the **Client ID** and **Client Secret**

### 3. Configure Supabase

1. Go to Supabase Dashboard → Authentication → Providers → Google
2. Enable Google provider
3. Paste **Client ID**
4. Paste **Client Secret**
5. Save

### 4. Add App Redirect URIs to Supabase

1. Go to Authentication → URL Configuration → Redirect URLs
2. Add:
   - `exp://**` (for Expo Go)
   - `glownome://**` (for builds)
3. Save

## Support

If Google Sign-In still doesn't work:

1. **Check console logs** - they show exactly what's happening
2. **Verify redirect URIs** - they must match exactly (or use wildcards)
3. **Check Google Cloud Console** - Supabase callback must be authorized
4. **Test email sign-in first** - make sure Supabase auth is working at all
5. **Try on different device** - some devices/networks block OAuth

The implementation follows Supabase's official Expo/React Native OAuth guide and should work reliably in both Expo Go and production builds.
